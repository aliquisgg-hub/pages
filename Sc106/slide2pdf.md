# 講義スライドをPDFに変換する方法

Windows パソコン上で講義スライドをPDFに変換するには，以下のようにします．

1.  Web ブラウザ（Edge, Chrome, Firefox など）で講義スライドを表示します
1.  そのページから印刷操作（Ctrl-P または 右上の3点メニューから「印刷」を選ぶなど）をし，プリンターの代わりに「PDFとして保存」等を選んで，PDF として保存します．
    -   その際，「シートごとのページ数」を設定すれば，A4版1ページあたりのスライド数を決められます（Edge の場合，「その他の設定」を開く必要があります）
    -   もちろん，プリンターを選んで，直接印刷することもできます．

※ Macやスマホやタブレットも類似の操作で可能だと思いますが，詳しくは知りません．

以上，一度お試しください．
