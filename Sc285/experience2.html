さらに...¶

  • 上の Code 1 ～ Code 5 を，それぞれ1つのファイル（拡張子は .py）に作成して，それぞれ実行してみよう．
    • Visual Studio Code からは，右上の実行ボタンで実行できる（ウィンドウの下部にターミナルが開いて結果が表示される）．
    • 最後の行が値を持つ「式」の場合，Jupyter Notebook のように，その値が表示されるわけではないので，Code 1 では 2+2 の結果は表示されない．
    • 同様の理由で，Code 2，Code 3 も，.show() を付けた形でないと画像は表示されない．
      • 画像ビューアなどの外部のプログラムを起動するプログラムは，（教室では）エクスプローラからファイルをダブルクリックしても実行できる．
