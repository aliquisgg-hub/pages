計算練習プログラムの改変

授業で扱った計算練習プログラム（1～10 の自然数の足し算を10問出題するプログラム）を自由に改変してみること．

  • ファイル名は drill2.py とし，Jupyter Notebook ではなく，単体の Python プログラムとして作成すること．

    • 複数種類作った場合は，drill3.py, drill4.py … のように，番号を変えていくこと．

  • ファイル中には，コメントで以下の内容を含めること．

    • 学生番号・氏名
    • どのように改変したかの説明
    • 参考にした資料 (書籍，Webページ等) があれば，そのリスト
      • 書籍の場合は，その書籍の著者，表題，出版社，参照したページ の情報を含めること．
      • Webページの場合は，著者・サイト名等，ページの表題，URL，閲覧日時 の情報を含めること．
      • 生成AIを用いた場合は，その生成AIの名称，URL，使用したプロンプトを記載すること

  • たとえば，以下のような改変が考えられる．

    • 10 問の問題に答えたのち，最後にまとめて採点結果(1問1点で採点する)を表示する．
      ヒント：
      • 一つ一つの問題の正解/不正解を記録するために，リストを用いるとよい（かもしれない）．
    • 1～10 の自然数の引き算の練習にする(答えは正の数になるようにする)．あるいは，足し算と引き算を混ぜて練習させるようにする．
      ヒント：
      • a - b の乱数の範囲をうまく決めてやる（bの適切な範囲はaの値に依存する）．あるいは，不適切な問題（正解が0以下の問題）が生成されたら，適切な問題ができるまで作り直すようにするとか．
      • 足し算と引き算を混ぜるなら，どちらにするかも乱数で決めてやるとよい．
    • 1問ごとに解答をチェックして，正解するまで次の問題に進めない（同じ問題を繰り返す）ようにする．
      ヒント：
      • 解答部分に反復を組み込む．
    • 10問の問題がすべて異なる問題となるようにする．
      ヒント：
      • 既に作った問題を記録するリストを用意しておいて，問題を作る度に，そのリストに同じ問題がないかチェックして，もし同じ問題があれば，今作った問題を（場合によっては何度も）作り直すようにする．
    • 穴埋め式の問題にする．例えば，6 + [ ] = 10 に対して4と答えさせるような形式にする．
    • などなど…

日数計算の関数

1901/1/1 を第1日として，1901/1/1～2099/12/31 の間の任意の年月日が何日目になるかを計算して返す関数 calcDate(year, month, day) を作成すること．

  • ファイルは Jupyter Notebook (calcDate.ipynb) でも，単体の Python プログラム (calcDate.py) でもよい．
  • ファイル中には以下の内容を含めること．
    • 学生番号・氏名 （Jupyter Notebook (calcDate.ipynb) の場合は markdown セルで，単体の Python プログラム (calcDate.py) の場合はコメントとして）
    • 関数 calcDate の定義
    • どう考えて作ったかの説明（Jupyter Notebook (calcDate.ipynb) の場合は markdown セルで，単体の Python プログラム (calcDate.py) の場合はコメントとして）
    • 参考にした資料 (書籍，Webページ等) があれば，そのリスト（Jupyter Notebook (calcDate.ipynb) の場合は markdown セルで，単体の Python プログラム (calcDate.py) の場合はコメントとして）
      • 書籍の場合は，その書籍の著者，表題，出版社，参照したページ の情報を含めること．
      • Webページの場合は，著者・サイト名等，ページの表題，URL，閲覧日時 の情報を含めること．
      • 生成AIを用いた場合は，その生成AIの名称，URL，使用したプロンプトを記載すること
  • コードの末尾には，以下の関数呼び出しを追加すること．
    print(calcDate(1901, 1, 1))     # ⇒ 1
print(calcDate(2020, 2, 28))    # ⇒ 43523
print(calcDate(2020, 3, 1))     # ⇒ 43525
print(calcDate(2020, 12, 31))   # ⇒ 43830
print(calcDate(2021, 1, 1))     # ⇒ 43831

ヒント：

  • 1901～2099 の間では，4の倍数の年は必ずうるう年で，それ以外にうるう年はない．
  • 1～12月の各月の1日の，1月1日からの日数は，
    通常の年は (0, 31, 59, 90, 120, 151, 181, 212, 243, 273, 304, 334)
    閏年は (0, 31, 60, 91, 121, 152, 182, 213, 244, 274, 305, 335)
    となるので，これを用いてもよい（用いなくてもよい）．

ソーティング（並べ替え）の関数A

要素がすべて数値の，任意の長さのリスト l を引数に取り，そのリストを昇順に（小さい値から大きい値の順になるように）並べ替える関数 mySortA(l) を書くこと．但し，以下の条件に沿って作成すること．

  • 関数 swap(l, i, j) を使用し，リストの書き換えはこの swap(l, i, j) を使用してのみ行うこと．

    def swap(l, i, j):
    l[j], l[i] = l[i], l[j]

  • 以下の考え方に基づくこと（以下リストの長さを nnn とする． すなわち，並べ替えの対象は l[0]l[0]l[0] ～ l[n−1]l[n-1]l[n−1] となる）．

    • l[0]l[0]l[0] ～ l[n−1]l[n-1]l[n−1] で最小の要素を見つけ，その添え字を得る（仮に mmm とする）．
    • swap 関数を用いて，l[0]l[0]l[0] と l[m]l[m]l[m] を入れ替える．
    • l[1]l[1]l[1] ～ l[n−1]l[n-1]l[n−1] で最小の要素を見つけ，その添え字を得る（仮に mmm とする）．
    • swap 関数を用いて，l[1]l[1]l[1] と l[m]l[m]l[m] を入れ替える．
    • l[2]l[2]l[2] ～ l[n−1]l[n-1]l[n−1] で最小の要素を見つけ，その添え字を得る（仮に mmm とする）．
    • swap 関数を用いて，l[2]l[2]l[2] と l[m]l[m]l[m] を入れ替える．
      　　　（以下同様に繰り返す．）
    • l[n−2]l[n-2]l[n−2] ～ l[n−1]l[n-1]l[n−1] で最小の要素を見つけ，その添え字を得る（仮に mmm とする）．
    • swap 関数を用いて，l[n−2]l[n-2]l[n−2] と l[m]l[m]l[m] を入れ替える．

    ※ このようにすれば，昇順に並べ替えられるはず．

なお，

  • ファイルは Jupyter Notebook (mySortA.ipynb) でも，単体の Python プログラム (mySortA.py) でもよい．
  • ファイル中には以下の内容を含めること．
    • 学生番号・氏名（Jupyter Notebook (mySortA.ipynb) の場合は markdown セルで，単体の Python プログラム (mySortA.py) の場合はコメントとして）
    • 関数 swap(l, i, j) の定義
    • 関数 mySortA(l) の定義
    • その他，必要なものは何でも（import 文とか，補助的な関数の定義とか）
    • 参考にした資料 (書籍，Webページ等) があれば，そのリスト（Jupyter Notebook (mySortA.ipynb) の場合は markdown セルで，単体の Python プログラム (mySortA.py) の場合はコメントとして）
      • 書籍の場合は，その書籍の著者，表題，出版社，参照したページ の情報を含めること．
      • Webページの場合は，著者・サイト名等，ページの表題，URL，閲覧日時 の情報を含めること．
      • 生成AIを用いた場合は，その生成AIの名称，URL，使用したプロンプトを記載すること
  • コードの末尾には，以下の関数呼び出しを追加すること．
    l1 = [1, -4, 2, -8, 5, -7]
mySortA(l1)
print(l1)                       # ⇒ [-8, -7, -4, 1, 2, 5]
l2 = [1, 4, 6, 2, 8, 5, 3, 7]
mySortA(l2)
print(l2)                       # ⇒ [1, 2, 3, 4, 5, 6, 7, 8]

ヒント：

  • リスト l の l[i] ～ l[j] で最小の要素を見つけ，その添え字を得る関数を， (例えば indexOfMin(l,i,j) のような名前で) 定義してみるとよいかも．

ソーティング（並べ替え）の関数B

要素がすべて数値の，任意の長さのリスト l を引数に取り，そのリストを昇順に（小さい値から大きい値の順になるように）並べ替えたリストを戻り値として返す関数 mySortB(l) を書くこと．但し，以下の条件に沿って作成すること．

  • 以下の考え方に基づくこと．

    • 空のリスト（[]）を用意する（仮に m とする）．
    • そのリスト m に，l の要素（l[0], l[1], l[2] …）を順に追加する．その際，
      • リスト m が常に昇順に並んでいるように， m の中の適切な位置を探して，そこに挿入する．
    • m に l の全ての要素を追加し終えたら，その m を戻り値として返す．

      • 書籍の場合は，その書籍の著者，表題，出版社，参照したページ の情報を含めること．

ソーティング（並べ替え）の関数C

要素がすべて数値の，任意の長さのリスト l を引数に取り，そのリストを昇順に（小さい値から大きい値の順になるように）並べ替えたリストを戻り値として返す関数 mySortC(l) を書くこと．但し，以下の条件に沿って作成すること．

  • 以下の考え方に基づくこと．

    • リスト l のコピーを用意する（仮に lc とする）
    • 空のリスト（[]）を用意する（仮に m とする）
    • lc が空になるまで以下を繰り返す
      • m の末尾に，lc 中の最小の要素を追加する
      • m に追加した要素を lc から取り除く
    • m を戻り値として返す．

なお，

  • ファイルは Jupyter Notebook (mySortC.ipynb) でも，単体の Python プログラム (mySortC.py) でもよい．
  • ファイル中には以下の内容を含めること．

    • 関数 mySortC(l) の定義
    • その他，必要なものは何でも（import 文とか，補助的な関数の定義とか）
    • 参考にした資料 (書籍，Webページ等) があれば，そのリスト（Jupyter Notebook (mySortC.ipynb) の場合は markdown セルで，単体の Python プログラム (mySortC.py) の場合はコメントとして）
      • 書籍の場合は，その書籍の著者，表題，出版社，参照したページ の情報を含めること．
      • Webページの場合は，著者・サイト名等，ページの表題，URL，閲覧日時 の情報を含めること．
      • 生成AIを用いた場合は，その生成AIの名称，URL，使用したプロンプトを記載すること
  • コードの末尾には，以下の関数呼び出しを追加すること
    l1 = [1, -4, 2, -8, 5, -7]
print(mySortC(l1))              # ⇒ [-8, -7, -4, 1, 2, 5]
print(l1)                       # ⇒ [1, -4, 2, -8, 5, -7]
l2 = [1, 4, 6, 2, 8, 5, 3, 7]
print(mySortC(l2))              # ⇒ [1, 2, 3, 4, 5, 6, 7, 8]
print(l2)                       # ⇒ [1, 4, 6, 2, 8, 5, 3, 7]

ヒント：

  • リスト l のコピーは，l[:] とするか，copyメソッドを用いて l.copy() としてもよい．
  • リスト l 中の最小の要素を見つけ，その添え字を得る関数を，(例えば indexOfMin(l) という名前で) 定義してみるとよいかも．
  • popメソッドが使えるかも．
