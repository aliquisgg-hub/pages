このファイルのような，拡張子 .ipynb のファイルは，Jupyter Notebook と呼ばれる形式である． Jupyter Notebook は，文章とプログラムを混在させて書くことができ，プログラムもファイル上で実行できる．

Jupyter Notebook では，文章はMarkdownセルに Markdown記法 と呼ばれる書き方で記述し，プログラムはコードセルに記述する．

下の2本の水平線の間（次のセルとの間）に，コードセルやMarkdownセルを，

  • 追加（セルの直下中央のボタン （マウスポインタが近づくと表示される），または左上のボタン），
  • 編集（テキストセルの編集の完了はセル右上のボタンから．再編集はダブルクリック），
  • 削除（セル右上のごみ箱アイコンをクリック）

してみよう．

# Code 2:

import io               # io ライブラリを読み込む（io.BytesIO などを使えるようにする）
import requests         # requests ライブラリを読み込む（requests.get などを使えるようにする）
from PIL import Image   # PIL ライブラリから Image モジュールを読み込む（Image.open などを使えるようにする）
                        # `import PIL.Image` よりも標準的な書き方

response = requests.get("https://www.python.jp/logo.png")   # URLからデータを取得する
Image.open(io.BytesIO(response.content))                    # 取得したデータの内容を，画像オブジェクトにする

最後の行は，画像オブジェクトを値とする「式」だが，Jupyter Notebook では，ノートブック内に表示される． 最後の行に .show() を付けて以下のようにして実行すると，Windows の画像ビューアが起動する． （これも試してみよう）

Image.open(io.BytesIO(response.content)).show()

さらに...¶

  • 上の Code 1 ～ Code 5 を，それぞれ1つのファイル（拡張子は .py）に作成して，それぞれ実行してみよう．
    • Visual Studio Code からは，右上の実行ボタンで実行できる（ウィンドウの下部にターミナルが開いて結果が表示される）．
    • 最後の行が値を持つ「式」の場合，Jupyter Notebook のように，その値が表示されるわけではないので，Code 1 では 2+2 の結果は表示されない．
    • 同様の理由で，Code 2，Code 3 も，.show() を付けた形でないと画像は表示されない．
      • 画像ビューアなどの外部のプログラムを起動するプログラムは，（教室では）エクスプローラからファイルをダブルクリックしても実行できる．
  • このファイル（experience.ipynb）を，Google Colaboratory でも実行してみよう．
    1. Google アカウントを用意する．
    2. Google ドライブのマイドライブに，Colab Notebooks というフォルダを作成する．
    3. Colab Notebooks に，書き込み前のこのファイル（experience.ipynb）をアップロードする．
    4. アップロードした experience.ipynb をダブルクリックする．
