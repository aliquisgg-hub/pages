融合原理による反駁の例

例1

000：（ゼロを表す）個体定数

sss：（「次の数」を表す）関数記号

0, 1, 2, 3, ⋯0,\ 1,\ 2,\ 3,\ \cdots0, 1, 2, 3, ⋯　⇒　0, s(0), s(s(0)), s(s(s(0))), ⋯0,\ s(0),\ s(s(0)),\ s(s(s(0))),\ \cdots0, s(0), s(s(0)), s(s(s(0))), ⋯
（s(⋯ )s(\cdots)s(⋯) の重なる数が「数」を表す）

AAA：（加算を表す）述語記号： A(x,y,z)A(x,y,z)A(x,y,z) は x+yx+yx+y が zzz に等しいことを表す．

前提 Γ={ ∀w A(0,w,w), ∀x∀y∀z (A(x,y,z)→A(s(x),y,s(z))) }\Gamma = \{\ \forall w\,A(0, w, w), \ \forall x \forall y \forall z\,(A(x, y, z)\rarr A(s(x), y, s(z)))\ \}Γ={ ∀wA(0,w,w), ∀x∀y∀z(A(x,y,z)→A(s(x),y,s(z))) }
　　（加算の定義を表す．「0+w=w0+w=w0+w=w」かつ「x+y=z ならば s(x)+y=s(z)x+y=z\ ならば\ s(x)+y=s(z)x+y=z ならば s(x)+y=s(z)」）

結論 α=∃v A(s(0),s(s(0)),v)\alpha = \exist v\,A(s(0), s(s(0)), v)α=∃vA(s(0),s(s(0)),v)
　　（「1+21+21+2 に等しい vvv が存在する」）

（ ¬α=∀v ¬A(s(0),s(s(0)),v)\lnot\alpha = \forall v\ \lnot A(s(0), s(s(0)), v)¬α=∀v ¬A(s(0),s(s(0)),v) ）

Γ⊨α\Gamma\models\alphaΓ⊨α を示すために，¬(Γ→α)\lnot(\Gamma\rarr\alpha)¬(Γ→α) を節形式に変換して反駁する．

¬(Γ→α)≡Γ∧¬α\lnot(\Gamma\rarr\alpha) \equiv \Gamma\land\lnot\alpha¬(Γ→α)≡Γ∧¬α より，Γ\GammaΓ と ¬α\lnot\alpha¬α を別個に節形式 SΓ\mathcal S_\GammaSΓ​ と S¬α\mathcal S_{\lnot\alpha}S¬α​ に変換すると，

SΓ={{ A(0,w,w) },⋯(1){ A(s(x),y,s(z)), ¬A(x,y,z) }}⋯(2)S¬α={{ ¬A(s(0),s(s(0)),v) }}⋯(3)\begin{array}{rlll}\mathcal S_\Gamma = \{&\{\ A(0, w, w)\ \},&&\cdots (1)\\ &\{\ A(s(x), y,s(z)),\ \lnot A(x, y, z)\ \}&\}&\cdots (2)\\ \mathcal S_{\lnot\alpha}=\{&\{\ \lnot A(s(0), s(s(0)), v)\ \}&\}&\cdots (3)\end{array}SΓ​={S¬α​={​{ A(0,w,w) },{ A(s(x),y,s(z)), ¬A(x,y,z) }{ ¬A(s(0),s(s(0)),v) }​}}​⋯(1)⋯(2)⋯(3)​

SΓ∪S¬α\mathcal S_\Gamma\cup\mathcal S_{\lnot\alpha}SΓ​∪S¬α​からの反駁は以下の通り． 1. { ¬A(s(0),s(s(0)),v)‾ }(3)2. { A(s(x),y,s(z))‾, ¬A(x,y,z) }(2)3. { ¬A(0,s(s(0)),z)‾ }1,2; σ1={ 0/x, s(s(0))/y, s(z)/v }4. { A(0,w,w)‾ }(1)5. □3,4; σ2={ s(s(0))/w, s(s(0))/z }\begin{array}{rll} 1.\ &\{\ \underline{\lnot A(s(0), s(s(0)), v)}\ \} &(3)\\ 2.\ &\{\ \underline{A(s(x), y,s(z))},\ \lnot A(x, y, z)\ \} &(2)\\ 3.\ &\{\ \underline{\lnot A(0, s(s(0)), z)}\ \} &1,2;\ \sigma_1=\{\ 0/x,\ s(s(0))/y,\ s(z)/v\ \}\\ 4.\ &\{\ \underline{A(0, w, w)}\ \} &(1)\\ 5.\ &\square & 3,4;\ \sigma_2=\{\ s(s(0))/w,\ s(s(0))/z\ \} \end{array}1. 2. 3. 4. 5. ​{ ¬A(s(0),s(s(0)),v)​ }{ A(s(x),y,s(z))​, ¬A(x,y,z) }{ ¬A(0,s(s(0)),z)​ }{ A(0,w,w)​ }□​(3)(2)1,2; σ1​={ 0/x, s(s(0))/y, s(z)/v }(1)3,4; σ2​={ s(s(0))/w, s(s(0))/z }​ ※ 反例としての vvv の値 (vσ1)σ2=s(s(s(0)))(v\sigma_1)\sigma_2=s(s(s(0)))(vσ1​)σ2​=s(s(s(0))) が加算の解（333 を表す）
