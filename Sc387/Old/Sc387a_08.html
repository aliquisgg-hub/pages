状態空間法
  状態空間集合(解空間)	Q = {p,q,r,…}
  オペレータ集合	O = {s,t,u,…}
  状態遷移関数	ψ: Q x O → Q ∪ {⊥}
	Q x O = {<p,s>|p∈Q, s∈O}
	⊥: 「未定義」を表わす記号
     オペレータsの前提条件(適用条件):
	現在の状態が下のような Q_s に属すこと
	Q_s = {p|p∈Q, ψ(p,s)≠⊥} ⊂ Q
  初期状態	q_i ∈ Q
  最終状態	Q_f ⊂ Q  (q_f ∈ Q)

  状態遷移	p → q
  　　　　	  s

	(p,q ∈ Q, s∈O, ψ: <p,s> |→ q)
	     　     　   i.e. ψ(p,s) = q

	  　 　 　  	  *
	p → … → q	p → q
	  s1 … sn  	  α (=s1 … sn)

	(p,q ∈ Q, α ∈ O^*)

  解: オペレータの系列	σ ∈ O^*
	         *
	s.t. q_i → q_f (⊂Q_f)
	         σ

5. 探索: 探索の基本的な考え方・盲目的探索法

 
グラフ
  ノード・節点 (node,vertex)
  リンク・弧 (link,arc)

  無向・有向
  連結・強連結

  木
  グラフの全域木

  根付き木(無向・有向)

グラフや木の表現
  明示的表現
    ノードの集合 {A, B, …}
      + リンク(ノード対)の集合 {<A,B>,…}
  暗黙的表現
    ノードの表現 {oo| … }
      + リンクの表現(successor関数)
    ※ 状態空間など

木探索の一般的な枠組
  begin
    S ← {root}
    loop
      p ← pick(S)
      if is_goal(p) then exit_as_success
      S ← remove(S,p) ∪ children(p)
      if empty(S) then exit_as_failure
    end loop
  end

  1. 節点の集合 S に根節点を入れる
  2. 以下の 2.1 ～ 2.4 を繰り返す
    2.1. S から節点を１つ取り出す(p とする)
    2.2. p が目標節点なら探索終了(成功)
    2.3. S から p を取り除き，
         代わりに p の子節点を追加する
    2.4. S が空集合なら探索終了(失敗)

  ※Sは探索の「最前線」

グラフの探索
   I. グラフであることを無視する．
      (同じところを何度も探索する)

  II. 1度探索した節点は記憶しておき，
      再び到達したときは無視する．

  ※課題 II. を上のように形式的に記述して見よう
         (T - 既に探索した節点の集合 - を用いる)

探索手法(戦略)
  ※2.1の「選び方」に依存する

  盲目的探索
    縦型探索
      … 最も最近(most recent)追加したものを選ぶ
         LIFO (Last In First Out)
      ※ バックトラック
    横型探索
      … 最も前に(least recent)追加したものを選ぶ
         FIFO (First In First Out)

6. 〃: 発見的探索・最良優先探索

 
[復習]
木探索の一般的な枠組

  1. 節点の集合 S に根節点を入れる
  2. 以下の 2.1 ～ 2.4 を繰り返す
    2.1. S から節点を１つ取り出す(p とする)
    2.2. p が目標節点なら探索終了(成功)
    2.3. S から p を取り除き，
         代わりに p の子節点を追加する
    2.4. S が空集合なら探索終了(失敗)

  ※Sは探索の「最前線」

発見的探索
    … 評価関数(ヒューリスティクス関数)を用いる
  山登り法
  最良優先探索

山登り法
  2.3 で，子節点のうちの最良のもの
  (評価関数値最大(最小)のもの)だけを追加
  (Sは常に高々1個，バックトラックしない)

最良優先探索
  ヒューリスティック関数f(p)を用いて，
  節点毎に評価値を計算して最良(最大または最小)の
  ものを選ぶ．評価関数の良し悪しで全てが決まる．

  1. 節点の集合 S に根節点を入れる
  2. 以下の 2.1 ～ 2.4 を繰り返す
    2.1. S から節点のうち_評価値最良のものを_
         1つ取り出す(p とする)
    2.2. p が目標節点なら探索終了(成功)
    2.3. S から p を取り除き，
         代わりに p の子節点を追加する
    2.4. S が空集合なら探索終了(失敗)

※図示

A*アルゴリズム(p.46)
  f(p) = g(p)+h(p)
    f(p): rootからpを通って目標に至る最短の距離
    g(p): rootからpまでの最短距離(木の場合 pの深さ)
    h(p): pから目標に至る最短の距離

  ※探索中は h(p)が未知なので，f(p)も未知
  ※木の場合，g(p)は既知．
    (一般のグラフの場合，「暫定値」
     - 別経路がありうるので → p.48 step 5 i～iii)
  ※以下木で考える．

  f'(p)=g(p)+h'(p)
    f'(p): f(p)の推定値
    h'(p): h(p)の推定値

  ※f'(p)を用いて最良優先探索を行なう(最小が最良)

  f'(p) ≦ f(p) i.e. h'(p) ≦ h(p) (楽観的な推測)
  ならば，必ず最適解(もっとも浅い解)が得られる

  h'(p)≡0 なら，横型探索
  h'(p) が h(p) に近いほど効率がよい

7. 〃: AND/OR木の探索・ゲームの木

 
縦型探索の再帰的な定義
  DFS(n):
    1. n の全ての子 m1～mk に対して 1.1，1.2 を行う
      1.1 DFS(mi) を行う．
      1.2 1.1 の結果が成功なら，3. へ行く
    2. m1～mk の全てで失敗の場合，nを失敗として
       DFS(n) を終える．
    3. nを成功として DFS(n) を終える．

AND/OR木
  AND節点・OR節点
  成功・失敗
    終端
    AND節点
    OR節点

  AND/OR木の探索 - 成功の部分木を見つける
    OR節点はどれか1つの分岐を選ぶ
    AND節点はすべての分岐を選ぶ
    全ての終端が成功

  例)

  ※全てORの木の探索 → 通常の木探索
  ※AND/ORグラフ - マージあり，バックリンクなし
  ※問題分割グラフはAND/ORが交互

ゲームの木 - 完全情報二人ゼロ和
            (最善手を選べばどちらかが必勝)
  勝ち - 成功・負け - 失敗 とすれば，AND/OR木
  探索に成功すれば(先手)必勝

  ※AND/ORを逆にすれば，後手のゲーム木になる

  評価値(局面評価)を利用した探索
    先読み → minimax 法

    例) p. 54, fig. 3.6

    α-β法 - 枝刈り

    例) p. 54, fig. 3.6

      名前
