1. 以下の5つの文を第一階述語論理の論理式で表現しなさい．

   ・ 動物は飛ばない．
   ・ 鳥は動物である．
   ・ 鳥は飛ぶ．
   ・ Leo は動物である．
   ・ Tweety は鳥である．

2. 1.の文を変換して得られた次の節集合を用いて，下の設問に答えなさい．

   { { ￢Animal(x), ￢Fly(x) },
     { ￢Bird(x), Animal(x) },
     { ￢Bird(x), Fly(x) },
     { Animal(Leo) },
     { Bird(Tweety) }
   }

  2-1. 「Leo は飛ばない」を (導出原理を用いて) 証明しなさい．
       (節集合に節 { Fly(Leo) } を追加して反駁する)
  2-2. 「Tweety は飛ぶ」を (導出原理を用いて) 証明しなさい．
       (節集合に節 { ￢Fly(Tweety) } を追加して反駁する)
  2-3. 「Tweety は飛ばない」を (導出原理を用いて) 証明しなさい．
       (節集合に節 { Fly(Tweety) } を追加して反駁する)
  2-4. 「Leo は飛ぶ」を (導出原理を用いて) 証明しなさい．
       (節集合に節 { ￢Fly(Leo) } を追加して反駁する)

   なさい．(論理式で記述しても日本語文で記述してもよい)
