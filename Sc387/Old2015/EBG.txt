〔Ⅰ〕説明の生成

[領域理論]
 1: { 椅子(X), ￢座れる(X), ￢安定(X) }			≒ 椅子(X) ← (座れる(X) ∧ 安定(X))
 2: { 座れる(X), ￢高さ(X,H), ￢範囲(30,H,60) }		≒ 座れる(X) ← (高さ(X,H) ∧ 範囲(30,H,60))
 3: { 安定(X), ￢底面積(X,S), ￢範囲(600,S,900) }	≒ 安定(X) ← (底面積(X,S) ∧ 範囲(600,S,900))
 4: { 範囲(A,X,B), ￢(A < X), ￢(X < B) }		≒ 範囲(A,X,B) ← ((A < X) ∧ (X < B))
[訓練例 a]
 5: { 色(a,白) }
 6: { 高さ(a,40) }
 7: { 底面積(a,800) }
 8: { 材質(a,木) }
[￢目標概念(a)]
 9: { ￢椅子(a) }
[反駁]
10: { ￢座れる(a), ￢安定(a) }				(9,1;  X=a)
11: { ￢高さ(a,H), ￢範囲(30,H,60), ￢安定(a) }		(10,2; X=a)
12: { ￢範囲(30,40,60), ￢安定(a) }			(11,6; H=40)
13: { ￢(30 < 40), ￢(40 < 60), ￢安定(a) }		(12,4; A=30,X=40,B=60)
14: { ￢安定(a) }					(13,事実x2)
15: { ￢底面積(a,S), ￢範囲(600,S,900) }		(14,3; X=a)
16: { ￢範囲(600,800,900) }				(15,7; S=800)
17: { ￢(600 < 800), ￢(800 < 900) }			(16,4; A=600,X=800,B=900)
18: { }							(17,事実x2)

※領域理論の各節を推論規則風に書いてみる
 1:  ⇒ 座れる(X)　安定(X)
     　 ------------------
     　      椅子(X)

 2:  ⇒ 高さ(X,H)　範囲(30,H,60)
     　 ------------------------
     　        座れる(X)

 3:  ⇒ 底面積(X,S)　範囲(600,S,900)
     　 ----------------------------
     　         安定(X)

 4:  ⇒ (A < X)　(X < B)
     　 ----------------
     　   範囲(A,X,B)

〔Ⅱ〕一般化

Ⅱ-1．このうちの述語：高さ・底面積・小なり が操作性基準を満たすので，そこから末端を切り離す．
      反駁部分も切り離す．

                 (A→30 < X→40)    (X→40 < B→60)                        (A→600 < X→800)    (X→800 < B→900)
                 ----------------------------------4                       --------------------------------------4
                      範囲(A→30,X→40,B→60)                                  範囲(A→600,X→800,B→900)
  高さ(X→a,H→40)    範囲(30,H→40,60)                 底面積(X→a,S→800)    範囲(600,S→800,900)
  -------------------------------------2                -------------------------------------------3
            座れる(X→a)                                             安定(X→a)
            座れる(X→a)                                             安定(X→a)
            -------------------------------------------------------------------1
                                        椅子(X→a)

Ⅱ-2．変数置換を元の変数に戻して再構成し，より一般的な表現にする

                 (A→30 < X→H )    (X→H  < B→60)                      (A→600 < X→S  )    (X→S   < B→900)
                 ----------------------------------4                     --------------------------------------4
                      範囲(A→30,X→H ,B→60)                                範囲(A→600,X→S  ,B→900)
  高さ(X   ,H    )    範囲(30,H    ,60)               底面積(X   ,S     )    範囲(600,S     ,900)
  -------------------------------------2              -------------------------------------------3
            座れる(X   )                                            安定(X   )
            座れる(X   )                                            安定(X   )
            ------------------------------------------------------------------1
                                        椅子(X   )

すなわち，

            (30 < H )    (H < 60)               (600 < S)    (S < 900)
            ---------------------4              ----------------------4
               範囲(30,H,60)                       範囲(600,S,900)
  高さ(X,H)    範囲(30,H,60)        底面積(X,S)    範囲(600,S,900)
  --------------------------2       ------------------------------3
          座れる(X)                           安定(X)
          座れる(X)                           安定(X)
          -------------------------------------------1
                           椅子(X)

〔Ⅲ〕マクロ化

上で得られた木の末端(葉)と根から，ひとつのホーン節を得る → 概念記述となる．

椅子(X) ← (高さ(X,H) ∧ (30 < H ) ∧ (H < 60) ∧ 底面積(X,S) ∧ (600 < S) ∧ (S < 900))
≒ { 椅子(X), ￢高さ(X,H), ￢(30 < H ), ￢(H < 60), ￢底面積(X,S), ￢(600 < S), ￢(S < 900) }
