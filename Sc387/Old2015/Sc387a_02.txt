状態空間法
　状態空間集合(解空間)	Q = {p,q,r,…}
　オペレータ集合	O = {s,t,u,…}
　状態遷移関数	ψ: Q x O → Q ∪ {⊥}
	Q x O = {<p,s>|p∈Q, s∈O}
	⊥: 「未定義」を表わす記号
　　 オペレータsの前提条件(適用条件):
	現在の状態が下のような Q_s に属すこと
	Q_s = {p|p∈Q, ψ(p,s)≠⊥} ⊂ Q
　初期状態	q_i ∈ Q
　最終状態	Q_f ⊂ Q　(q_f ∈ Q)


　状態遷移	p → q
　　　　　	　s

	(p,q ∈ Q, s∈O, ψ: <p,s> |→ q)
	　　 　　　 　　 i.e. ψ(p,s) = q

	　　 　 　　	　*
	p → … → q	p → q
	　s1 … sn　	　α (=s1 … sn)

	(p,q ∈ Q, α ∈ O^*)

　解: オペレータの系列	σ ∈ O^*
	　　　　 *
	s.t. q_i → q_f (⊂Q_f)
	　　　　 σ
