木探索の一般的な枠組
　begin
　　S ← {root}
　　loop
　　　if empty(S) then exit_as_failure
　　　p ← pick(S); S ← remove(S,p)
　　　if is_goal(p) then exit_as_success
　　　S ← S ∪ children(p)
　　end loop
　end

　1. 節点の集合 S に根節点を入れる
　2. S が空集合なら探索終了(失敗?)
　3. S から節点を１つ取り出す(p とする)
　   （その節点 p は S から取り除く）
　4. p が目標節点なら成功(探索終了?)
　5. S に p の子節点を追加する
　6. 2 に戻る

　※Sは探索の「最前線」

探索手法(戦略)
　※3. の「選び方」に依存する

　盲目的探索
　　縦型探索
　　　… 最も最近(most recent)追加したものを選ぶ
　　　　 LIFO (Last In First Out)
　　　※ バックトラック
　　横型探索
　　　… 最も前に(least recent)追加したものを選ぶ
　　　　 FIFO (First In First Out)

グラフの探索
　 I. グラフであることを無視する．
　　　(同じところを何度も探索する)

　II. 1度探索した節点は記憶しておき，
　　　再び到達したときは無視する．

発見的探索
　　… 評価関数(ヒューリスティクス関数)を用いる
　山登り法
　最良優先探索

山登り法
　5. で，子節点のうちの最良のもの
　(評価関数値最大(最小)のもの)だけを追加
　(Sは常に高々1個，バックトラックしない)

最良優先探索
　(3. で，)ヒューリスティック関数f(p)を用いて，
　節点毎に評価値を計算して最良(最大または最小)の
　ものを選ぶ．評価関数の良し悪しで全てが決まる．

　1. 節点の集合 S に根節点を入れる
　2. S が空集合なら探索終了(失敗?)
　3. S に含まれる節点のうち_評価値最良のものを_
　    １つ取り出す(p とする)
　   （その節点 p は S から取り除く）
　4. p が目標節点なら成功(探索終了?)
　5. S に p の子節点を追加する
　6. 2 に戻る
