JavaScript いろいろ

ブラウザによって動いたり動かなかったりするのでご了承のほどを． （主に Firefox で作成しているため，IEでは動かないことが多いかも．）

  • タートルグラフィクス
    HTML5 の CANVAS を使用して，オブジェクト指向風に書いてみた． プログラムの本体は turtle.js． サンプルを読み込むのに，http_request.js も使用．
  • 擬似対話プログラム（Eliza風のもの）- その1，その2
    「猪股 俊光，益崎 真治： Schemeによる記号処理入門，森北出版 (1994)」の「第9章 コンピューターとの対話」を参考に， Sc289(2) の授業用に作成．
  • 英語(の部分系?)のトップダウンパーザ （HTML版のサンプル，SVG版のサンプル）
    なんちゃって英語パーザ（再帰的下向き構文解析）．Sc289(2) の授業用に作成． いい加減な文法と語彙は本体のファイル tdp.js を参照のこと．
    木構造の表示は，HTML版は print_tree.js，SVG版は draw_tree.js を参照のこと．

    [xml を使って xhtml に SVG を埋め込んだ版も作ってみた: tdp_sample.xhtml]

  • ハノイの塔（n=4，n=3）
    模擬授業用に作成．
  • 水差しの問題
    状態空間法のデモンストレーション．オープンキャンパス用に作成． （参考）
  • n クイーン問題
    実行ボタンで実行．部分的に書き直すことも可能．リセットボタンで書き直しを元に戻せる． KCH対象特別授業用に作成．（参考）
  • 数独用ツール
    ブラウザ判別用ライブラリ user_agent.js と CSSサポートライブラリ jcss.js を使用．
  • ソリティア
    いわゆる peg solitaire のプログラム. 手順を記録して undo/redo が可能． cookie_db.js により，クッキーを用いて，手順に名前をつけて保存できる． 手順を JavaScript の配列リテラルのテキストデータとして読み書きする機能もあり． クッキーで手順を保存する機能を抜いて，IEでも動くバージョンも作ってみた．
  • 電卓
    ブックマークレット版もあり． 同一ウィンドウ版（サイドバーなどに最適）と 新規ウィンドウ版． （リンクをブックマークに登録すれば使える）
    関数電卓も作ってみた． （ブックマークレット， 同一ウィンドウ版 新規ウィンドウ版 ）
  • JavaScript簡易実行環境
    JavaScript のコードを実行．値も見られるし，document.write() 等の実行による出力も見られる． 情報科学応用演習I の授業用に作成． （残念ながら，最近のブラウザではセキュリティの関係でうまく動かないかも．）

以下はライブラリ．

  • 関数トレース用ライブラリ tracer.js
    JavaScript の関数の実行をトレースするためのライブラリ． トレース情報は別のウィンドウに表示される．折りたたみも可． サンプルも参照のこと． 情報科学応用演習I の授業用に作成．
  • クッキーデータベース(?)ライブラリ cookie_db.js
    クッキーを使って，テキストやオブジェクトを保存するライブラリ． 使い方はサンプルを参照のこと．
  • スタイルシート拡張用ライブラリ css_ext.js
    ブラウザの種類ごとにスタイルシートを変えるライブラリ． 詳細はサンプルを参照のこと． ブラウザ判別用ライブラリ user_agent.js， onload イベントのハンドラを追加するためのライブラリ onload_hook.js （そのサンプル）も使用．
  • 多重イメージ用ライブラリ layeredimgs.js
    複数の画像を重ね合わせるためのライブラリ．サンプルも参照のこと． 一部の画像をプログラムで置き換えるなどすれば，簡単なアニメーションにも応用可能． （上の「水差しの問題」の3ページ目の状態遷移図でも類似のことをしている）
    onload イベントのハンドラを追加するためのライブラリ onload_hook.js （そのサンプル）も使用．
