この文書では，Windows 版 Visual Studio Code のごく初歩的な使用法について記述する． 他の OS の場合は，必要に応じて適宜読み替えていただきたい． インターネット上にも様々な情報があるので，各自研究されたい．

なお，インストール方法と日本語化・初期設定については，別に文書を作成したので，そちらを参照されたい

文字の入力・削除・編集

文字単位での入力・削除・編集はメモ帳と同様に行える．

起動方法

VS Code も，通常のアプリケーションと同様に様々な起動方法があるが，スタートボタンから起動することを推奨する．

方法1

「スタートボタン」→「V」→「Visual Studio Code」→「Visual Studio Code」で起動する．

方法2

「スタートボタン」をクリックした後，キーボードから名前を「visu...」と入力していき， 適当なところで，表示されている「Visual Studio Code」を選択する． （CSLドメインPCでは，「visu」で選択肢が1つに絞られる）

その他の起動方法

CSLドメインPC（教室のPC）では，この項に記述する起動方法を利用すると，いくつかの不具合を生じるため， その利用を推奨できないが，自宅等のPCで利用する際の参考として記しておく．

編集するファイルの右クリックメニューで起動

VS Code のインストール時の「追加タスクの選択」で， 「エクスプローラーのファイル コンテキスト メニューに [Code で開く] アクションを追加する」 を選択していた場合，Windows のエクスプローラ等でファイルのアイコンを右クリックして表示されるメニューから 「Code で開く」を選んで VS Code で開くことができる．
（CSLドメインPC（教室のPC）では，この方法を用いると，各種設定が無効になるので，推奨できない）

すぐに起動できるように「ピン留め」をする

  • 「スタートボタン」→「V」→「Visual Studio Code」→「Visual Studio Code」のアイコンを右クリックして， 表示されたメニューから「スタート画面にピン留めする」を選ぶと，右側にアイコンが「ピン留め」される． （下図の①）
  • 「スタートボタン」→「V」→「Visual Studio Code」→「Visual Studio Code」のアイコンを右クリックして， 表示されたメニューから「その他」→「タスクバーにピン留めする」を選ぶと，タスクバー（画面の下の部分） にアイコンが「ピン留め」される．（下図の②）

いずれの場合も，これ以後は「ピン留め」されたアイコンをクリックするだけで起動できる．
（CSLドメインPC（教室のPC）では，サインアウト時にピン留めしたアイコンが消えてしまうので，推奨できない）

デスクトップにショートカットを作成する

VS Code のインストール時の「追加タスクの選択」で， 「デスクトップ上にアイコンを作成する」 を選択していた場合，デスクトップ上にアイコン（ショートカット）が作成されている．

作成されていなかった場合でも，「スタートボタン」→「V」→「Visual Studio Code」→「Visual Studio Code」のアイコンを デスクトップにドラッグすると，そこ（デスクトップ上）にショートカットが作成される．（前項の図の③）

これ以後は，作成したショートカットのダブルクリックで起動できる． また，開きたいファイルのアイコンをショートカットにドラッグ＆ドロップするとそのファイルを開くことができるが， それ以後，初期設定の「フォルダーを開く」で設定したフォルダーが自動的に開かなくなるので， あまり好ましくない． （「ファイル」メニューの「フォルダーを開く」か「最近使用した項目を開く」で元に戻せるが……）

既存のファイルを開く

  • VS Code のエクスプローラーを利用する場合
    1. エクスプローラーが表示されていない場合，右上のエクスプローラーのアイコンをクリックする．
    2. エクスプローラ内に表示されているファイルをクリックする．
  • 「ファイル」メニューの「ファイルを開く」

    メモ帳などの通常のアプリケーションと同様に，「ファイル」メニューの「ファイルを開く」 （または Ctrl-O）でファイルを開くこともできる．

ファイルの新規作成

テンプレートファイルなどの既存のファイルを元にして新しいファイルを作成するときは， 次項を参照すること．
  • VS Code のエクスプローラーで「新しいファイル」ボタンを用いる． (普段は見えないが，マウスカーソルを近づけると現れる)
  • 「ファイル」メニューの「新規ファイル」

    メモ帳などの通常のアプリケーションと同様に，「ファイル」メニューの「新規ファイル」 （または Ctrl-N）でファイルを新規作成することもできる．

ファイルのコピーと名前の変更

  • VS Code のエクスプローラーでは，Windows のエクスプローラーと同様に，ファイルを右クリックして表示されるメニューの 「コピー」や「名前の変更」で，ファイルの（クリップボードへの）コピー（Ctrl-C）や名前の変更（F2）が行える．
  • また，（クリップボードの内容がファイルであれば，）余白部分を右クリックして表示されるメニューの「貼り付け」でファイルの貼り付け （Ctrl-V）が行える．
  • 既存のファイル（例えばテンプレートファイル等）のコピーを作成して名前を変更する場合は，ショートカットキーを活用すれば， 元のファイルをクリックして選択した後，Ctrl-C, Ctrl-V, F2 と続けてキー操作して，新しいファイルの名前を入力すればよい．

ファイルの保存

  • VS Code では，通常のアプリケーションと同じように，「ファイル」メニューの「保存」，「名前を付けて保存」で， （上書き）保存，（任意の場所へ）名前を付けて保存ができる．
  • それ以外に，「ファイル」メニューの「すべて保存」で，変更のあったファイルのすべてを上書き保存することができる （変更のあったファイルは，ファイル名タブのファイル名の後に白丸がマークされる．下図参照）．
    「すべて保存」は，エクスプローラーの「開いているエディター」のリストを開いて，「すべて保存」ボタンで行うこともできる．（下図）

印刷（拡張機能 Print の利用）

（編集中のテキストを印刷するためには，拡張機能 Print を追加しておく必要がある．以下では，この Print が既に追加されていると仮定する．）

プログラム，テキスト等の印刷

  1. 右上にあるプリンタアイコン をクリックする．
  2. ブラウザが開いて印刷可能な状態になるので，そこから印刷する．
テキストを選択した状態で操作した場合，その選択された部分だけが印刷される． ファイル全体を印刷する場合は，テキストを選択していない状態で行うこと．

Jupyterノートブックファイル (.ipynb) の印刷

  • Jupyterノートブック形式のファイルはプリンタアイコン が表示されないので， いったんHTML形式にエクスポートしてから Firefox などのブラウザで開き，そのブラウザから印刷するとよい．
