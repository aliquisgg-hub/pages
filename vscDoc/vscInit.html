以下，Windows 版の Visual Studio Code で初期設定する際の手順を記述する． 他の OS の場合も同じような手順となるが，必要に応じて適宜読み替えていただきたい．

A. 最初の起動時

  1. 最初に起動した際，右下の小さいウィンドウに，ユーザーの利用データを Microsoft に送信する旨のメッセージが出た場合，とりあえず「×」をクリックして消しておく．
    （出なかった場合，この項の内容は飛ばしてよい） （参考：ユーザーの利用データを Microsoft に送信させないようにするには）
    ↓クリックすると画像が拡大します

B. 日本語化

  1. 「View」メニューから「Command Palette...」を選ぶ．（Ctrl+Shift+P キーまたは F1 キーでもよい）
    ↓クリックすると画像が拡大します
  2. 開いたコマンドパレットの最上段の検索欄に「config」と入力し， 絞り込まれたコマンドから「Configure Display Language」を選ぶ．
    ↓クリックすると画像が拡大します
  3. 表示されたリストから「日本語」を選んでクリックする．
    ↓クリックすると画像が拡大します
  4. 小さいウィンドウが開いたら，「Restart」をクリックする． Visual Studio Code が再起動して，日本語化が完了する．

C. 初期設定

最初に表示されている「VS Code を開始する」のページで，テーマ（エディタの配色などの見た目）の設定などができるので，お好みで変えてもよい． 一度閉じた「VS Code を開始する」のページを再度開きたい場合は，「ようこそ (Visual Studio Code)」のページの右側の「チュートリアル」から開くことができる．
日本語化したにもかかわらず，設定の途中で英語に戻った場合は，Visual Studio Code をいったん終了してから，もう一度起動するとよい．

フォルダーを開く

Visual Studio Code には，エクスプローラーの機能が備わっているので，よく使うフォルダーを開いておくと， 次回から自動的にそのフォルダーを開いてくれるので便利である．
（Sc185(2) IT応用演習を受講するなら，public_html を開いておくとよい）

  1. 左側にエクスプローラーが表示されていない場合は，左上のエクスプローラー・アイコンをクリックして エクスプローラーを表示させる．
    ↓クリックすると画像が拡大します
  2. エクスプローラーに「フォルダーを開く」ボタンが表示されているなら，それをクリックして 適切なフォルダーを選択する．
    （Sc185(2) IT応用演習を受講するなら，public_html を開いておくとよい）
    ↓クリックすると画像が拡大します
すでにフォルダーが選択されていて，他のフォルダーを開きたい場合は，「ファイル」メニューの「フォルダーを開く」を選んで，同様に選択する．
「このフォルダー内のファイルの作成者を信頼しますか?」というメッセージウィンドウが開いた場合は， フォルダ内に（作成者不詳の）怪しいファイルがないことを確認して，「はい、作成者を信頼します」 をクリックする．

各種設定の設定方法

Visual Studio Code の各種の設定は，左下の歯車アイコンのメニューから「設定」を選び （または Ctrl-, キーでもよい），「設定」のページを開いて行う．

↓クリックすると画像が拡大します

「設定」のページには多数の設定項目があるが，ページ先頭の「設定の検索」にキーワードを 入れることで，表示を絞り込むことができる．

↓クリックすると画像が拡大します

設定項目をリセットする（設定前の元の値に戻す）には，その項目の左の歯車アイコン （マウスカーソルを近づけると表示される）をクリックして現れるメニューから， 「設定をリセット」を選ぶ．

↓クリックすると画像が拡大します

おすすめの設定項目

テキスト エディター > Editor: Render Whitespace

（whitespace で検索するとよい）

半角スペースを目に見えるように表示する（薄い中黒「･」で表示する） かどうかを設定できる．既定値の selection は，文字列として選択したときにのみ， そのように表示されるが，all にしておくと，常にそのように表示される．

all にしておくと，行末の余分なスペースや，全角スペースを見分けることができる†ので， all にするのがおすすめ．
（† 全角スペースは「薄い中黒」ではないスペースとして見分けられる．）

テキスト エディター > Editor: Word Wrap

（wordwrap で検索するとよい）

長い行の折り返しの仕方を決める設定項目．既定値の off では折り返しをしないが， この場合，長い行はウィンドウの右に「はみ出し」て見えなくなるので，on にして， ウィンドウの右端で折り返す設定にしておくとよい．

この設定項目の設定値にかかわらず，「表示」メニューの「右端での折り返し」 （Alt-Z でもよい）で，折り返しをするかしないかを切り替えられる．

テキスト エディター > ファイル > Files: Auto Guess Encoding

（encoding で検索するとよい）

ファイルを読み込む際に，文字コードを自動的に推定して設定してくれる機能． 既定値では「無効」になっているが，チェックを付けて「有効」にしておく方が便利かもしれない． 推定された文字コードは右下に表示される．

文字コードの推定に失敗した（間違えた）場合は，右下に表示された文字コードの表示をクリックし， 「エンコード付きで再度開く (Reopn with Encoding)」を実行して，文字コードを指定して開くとよい．

↓クリックすると画像が拡大します

アプリケーション > 更新 > Update: Mode

（update で検索してもよい）

Visual Studio Code の更新プログラムがリリースされたときの取り扱いを設定する． 自宅等で使用している場合は，既定値の default のままにしておくのが良いが， CSLドメインのPCでは，一般ユーザは更新ができないので，none にしておくと，更新を促すメッセージ （下図参照）が表示されなくなる．

拡張機能 > Emmet > Emmet: Show Expanded Abbreviation

（abbreviation で検索してもよい）

Visual Studio Code では，HTML を Emmet と呼ばれる略記法で入力し， それを自動的に HTML に変換（展開）する機能が組み込まれている （cf. Emmet snippets）． この機能はうまく使えば便利であるが，慣れていないと，予期せぬ変換が勝手に行われて， かえって混乱を招く場合がある．そのため，初心者はこの機能を無効にしておく方が良い． 無効にする場合は，この設定項目を never にする．

拡張機能 > HTML > HTML: Auto Closing Tags

（tags で検索してもよい）

Visual Studio Code では，HTML のタグを入力したときに対応する閉じタグを自動的に 挿入したり，「</」と入力すると，その場所より前でまだ閉じられていない最も近い開きタグに対応する閉じタグを自動的に挿入したりするようになっている．この機能も，慣れていないと，予期せぬ挿入が勝手に行われて， かえって混乱を招く場合がある （cf. Close tags）． そのため，初心者はこの機能を無効にしておく方が良いかもしれない． 無効にする場合は，この設定項目のチェックを外す．

その他の設定項目

ウィンドウ > Auto Detect Color Scheme

（scheme で検索してもよい）

ウィンドウの配色（ダークカラー（暗色）にするかライトカラー（明色）にするか）を，Windows のシステムカラーに合わせるための設定．デフォルトではダークカラー（暗色）になっているが，チェックを付けて有効にすると，通常はライトカラー（明色）になる．お好みで決めるとよい．

アプリケーション > テレメトリ > Telemetry: Telemetry Level

（telemetry で検索してもよい）

ユーザーの利用データを Microsoft に送信するかどうかを設定する． all, error, crash, off のいずれかの値を指定する． 既定値は all で，この Visual Studio Code がクラッシュ（エラーにより停止すること）したときの情報（クラッシュレポート）とそれ以外のエラー情報，および通常の利用状況のデータを送信するが，off にすると，すべての情報が送信されなくなる．

D.〔参考〕拡張機能

Visual Studio Code は，「拡張機能」を後から追加することで，機能を拡張することができる． 「拡張機能」は，以下の手順で追加できる．

  1. 左の拡張機能アイコン をクリックしてサイドバーを表示する．
  2. サイドバー上部の検索窓で検索するなどして，目的の拡張機能を見つける．
  3. 見つけた拡張機能の「インストール」ボタンをクリックする．（「インストールしています」ボタンに変わる）
  4. 「インストールしています」ボタンが「再起動が必要です」ボタンに変わった場合は，それをクリックして再起動させる．
  5. 「インストールしています」ボタンまたは「再起動が必要です」ボタンが歯車ボタンに変わればインストール完了．

拡張機能の例（おすすめの拡張機能）

W3C Web Validator（Sc185(2) 受講者向け）

  1. 「w3c」で検索するとよい．
  2. 「インストールしています」ボタンが歯車ボタンに変わり，左下に が表示されたら， インストール完了．

この拡張機能 W3C Web Validator の使用法はこちら．

Print

  1. 「print」で検索するとよい．
  2. インストールの際，下図のような確認が表示されるので，「発行元を信頼 &インストール」をクリックする．
  • 編集中のテキストを印刷するための拡張機能．
  • カラーもそのまま印刷できる．
  • Jupyter Notebook のような複雑なファイルは印刷できない．
  • 使用法はこちら．

Python と Jupyter（Sc188(2), Sc285(1), Sc288(2) 受講者向け）

  1. Python は「python」，Jupyter は「Jupyter」で検索するとよい．
  2. Python をインストールすると，同時に Pylance と Python Debugger が自動的にインストールされる．
  3. Jupyter をインストールすると，他に4つの拡張機能（Jupyter Cell Tags, Jupyter Keymap, Jupyter Notebook Renderers, Jupyter Slide Show）が自動的にインストールされる．
  4. いずれの場合も，検索窓を空欄にして，すべての拡張機能のインストールが完了するのを待つとよい．
